# Universal Estate & Emergency Organizer

A self-contained, browser-based organizer for documenting important people, legal roles, records, assets, obligations, care instructions, and emergency actions.

## Use

Open the published site in Chrome or Microsoft Edge. Complete **Welcome & Setup** first so names and contact information can be reused throughout the organizer.

- The application does not automatically save information in browser storage.
- Use **Save / Export** to download a JSON backup.
- Use **Import backup** to continue editing later.
- Exported JSON is not encrypted; store it in a protected location.
- Do not enter passwords, PINs, recovery codes, seed phrases, security answers, complete Social Security numbers, or full account numbers.
- The final password worksheet is intentionally blank and intended for handwriting after printing.

The site is static and has no server-side database or account system.
